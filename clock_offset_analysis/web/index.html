Method and scope

Estimate on raw timestamps in [08:00, 11:00). Validate on [11:00, 12:00). Trim ten minutes from both ends of each reference window so every candidate has equal pairing opportunity. A timestamps are retained only if B readings exist for every tested offset within that same raw-time window. No interpolation or cross-window pairs are used.

Pearson correlation compares shape; MAE measures absolute temperature disagreement; mean signed error is B minus A. Shape alignment cannot establish calibration accuracy, physical response equality or cold-storage safety. Assess competing peaks and residual bias before recommending a timing investigation.
